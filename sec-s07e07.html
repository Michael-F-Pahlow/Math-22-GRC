    Section 7.7 Episode 7: Dividing with Variables

    Episode 7 Learning Goals.

    • Interpret and perform calculations involving negative exponents
      🔗
      🔗
    • Interpret and perform calculations involving zero exponent
      🔗
      🔗
    • Divide a polynomial by a term.
      🔗
      🔗
    🔗
    🔗
    Let’s think about what happens in this situation:
    \begin{equation*} \frac{x^5}{x^2} \end{equation*}
    Let’s unpack the exponents:
    \begin{equation*} \frac{x\cdot x\cdot x\cdot x\cdot x}{x \cdot x} \end{equation*}
    Each divided x cancels out one of the multiplied x’s:
    \begin{equation*} x \cdot x \cdot x = x^3 \end{equation*}
    Notice that we ended up subtracting the exponents:
    \begin{equation*} \frac{x^5}{x^2 = x^{5-2} \end{equation*}
    🔗

    Exponent Property Four.

    Let \(m\) and\(n\) stand for two numbers (that may be different from problem to problem).
    🔗
    If you have the base \(x\) raised to a power, and then you divide by that same based raised to a different power, you should subtract the two exponents.
    \begin{equation*} \frac{x^m}{x^n}=x^{m-n} \end{equation*}
    🔗
    🔗

    Example 7.7.1.

    Simplify
    \begin{equation*} \frac{x^{70}}{x^{42}} \end{equation*}
    🔗
    Solution: It would be tedious to write out 70 and 42 \(x\)’s, so we use an exponent property.
    \begin{equation*} \frac{x^{70}}{x^{42}}= x^{70-42}=x^{28} \end{equation*}
    🔗
    🔗

    Exponent Property Five.

    If you see something (besides zero) raised to the power 0, the result of that is 1:
    \begin{equation*} x^0=1 \end{equation*}
    🔗
    🔗

    Makes Sense, Right?

    If we simplified
    \begin{equation*} \frac{x^3}{x^3} \end{equation*}
    using the exponent property, we would get
    \begin{equation*} \frac{x^3}{x^3} = x^{3-3} = x^0 \end{equation*}
    But at the same time, when you divide something by itself, the result is always 1:
    \begin{equation*} \frac{x^3}{x^3} = 1 \end{equation*}
    That’s why it makes sense to have \(x^{0}=1\text{.}\)
    🔗
    🔗

    Exponent Property Six.

    If you see something raised to a negative power, that’s asking you to take the reciprocal:
    \begin{equation*} x^{-4} = \frac{1}{x^4} \end{equation*}
    🔗
    🔗

    Makes Sense, Right?

    If we calculated
    \begin{equation*} \frac{x^3}{x^5} \end{equation*}
    using the exponent property, we would get
    \begin{equation*} \frac{x^3}{x^5} = x^{3-5}=x^{-2} \end{equation*}
    But at the same time, if we unpack the exponents:
    \begin{equation*} \frac{x^3}{x^5} = \frac{x\cdot x\cdot x}{x\cdot x \cdot x\cdot x \cdot x} \end{equation*}
    Three of the multiplied \(x\)’s are cancelled by three of the divided \(x\)’s, leaving:
    \begin{equation*} \frac{1}{x\cdot x} = \frac{1}{x^2} \end{equation*}
    That’s why it makes sense to have \(x^{-2}=\frac{1}{x^2}\)
    🔗
    🔗
    When we are dividing a polynomial by a term
    \begin{equation*} \frac{2x+6}{3} \end{equation*}
    you can divide each part of the polynomial separately:
    \begin{equation*} \frac{2x}{3}+\frac{6}{3} \end{equation*}
    \begin{equation*} \frac{2x}{3}+2 \end{equation*}
    🔗

    Makes Sense, Right?

    When we learned about fractions, we learned that when we were adding or subtracting two fractions with the same denominator, we just need to add the numerators:
    \begin{equation*} \frac{2}{7}+\frac{4}{7} = \frac{2+4}{7} \end{equation*}
    When we divide a polynomial, we’re just following this process backward.
    \begin{equation*} \frac{2+4}{7}=\frac{2}{7}+\frac{4}{7} \end{equation*}
    🔗
    🔗

    Example 7.7.2.

    Divide
    \begin{equation*} \frac{9x^5-x^4+x^3}{x^2} \end{equation*}
    🔗
    Solution: Divide each term of the numerator separately:
    \begin{equation*} \frac{9x^5}{x^2}-\frac{x^4}{x^4}+\frac{x^3}{x^2} \end{equation*}
    Then we can use the exponent properties to simplify each piece:
    \begin{equation*} 9x^{5-2}-x^{4-2}+x^{3-2} \end{equation*}
    \begin{equation*} 9x^3-x^2+x \end{equation*}
    🔗
    🔗

    Example 7.7.3.

    Divide
    \begin{equation*} \frac{6x^2+8x}{2x} \end{equation*}
    🔗
    Solution: Divide each term of the numerator separately:
    \begin{equation*} \frac{6x^2}{2x} + \frac{8x}{2x} \end{equation*}
    In the first fraction, the \(6\div 2\) becomes 3, and the \(x^{2}\div x\) becomes \(x\text{.}\) In the second fraction, the \(8\div 2\) becomes 4, and the \(x\div x\) cancels out to 1.
    \begin{equation*} 3x+4 \end{equation*}
    🔗
    🔗

    Exponent Properties.

    Here is a list of the exponent properties from Episodes 6 and 7
    1. \(\displaystyle x^m x^n = x^{m+n}\)
      🔗
      🔗
    2. \(\displaystyle (x^a)^b = x^{a\cdot b}\)
      🔗
      🔗
    3. \(\displaystyle (xy)^p = x^p y^p\)
      🔗
      🔗
    4. \(\displaystyle \frac{x^m}{x^n}=x^{m-n}\)
      🔗
      🔗
    5. \(\displaystyle x^0=1\)
      🔗
      🔗
    6. \(\displaystyle x^{-p} = \frac{1}{x^p}\)
      🔗
      🔗
    🔗
    🔗
