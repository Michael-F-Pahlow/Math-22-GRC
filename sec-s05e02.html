    Section 5.2 Episode 2: Evaluating Formulas

    Episode 2 Learning Goals.

    • Evaluate given formulas to calculate desired quantities.
      🔗
      🔗
    🔗
    🔗

    Episode 2 Learning Goals.

    • Evaluate ("plug in")
      🔗
      🔗
    🔗
    🔗
    In the previous episode, we noted that an expression represents a calculation that cannot be complete because it contains an unknown number (a variable).
    🔗

    Definition 5.2.1.

    Evaluating an expression is completing the calculation after the value of the variable becomes known. In other words, we "plug in" a specific number for a variable.
    🔗
    🔗

    Example 5.2.2.

    In the previous episode, we represented the cost of buying a dozen eggs by \(C\text{,}\) so that the total cost of buying 3 dozen eggs was
    \begin{equation*} 3C \end{equation*}
    You enter the grocery store and find the cost of a dozen eggs is currently $2.18. Use this info to complete the calculation in the expression.
    🔗
    Solution: Replace the \(C\) in the formula with 2.18, so that instead of 3 times C, we now have 3 times 2.18:
    \begin{equation*} 3(2.18) = 6.54 \end{equation*}
    The total cost is $6.54
    🔗
    🔗

    Example 5.2.3.

    In the previous episode, for a student with exam scores 80%, 90%, and an unknown score \(x\text{,}\) the expression representing their average score was:
    \begin{equation*} \frac{80\% + 90\% + x}{3} \end{equation*}
    The student takes their third exam and earns a score of 72%. Use this info to complete the calculation in the expression.
    🔗
    Replace the \(x\) in the formula with 72\%:
    \begin{equation*} \frac{80\%+90\%+72\%}{3} = 80.666666666...\% \approx 80.67\% \end{equation*}
    Their exam average is 80.67%.
    🔗
    🔗
    Be particularly careful when doing evaluation with negative numbers.
    🔗

    Example 5.2.4.

    Given that \(x=-3\text{,}\) evaluate the expression:
    \begin{equation*} x^2 \end{equation*}
    🔗
    The expression is asking us to square \(x\text{.}\) Since the value of \(x\) is -3, we need to square -3.
    🔗
    It would not be correct to write \(-3^2\text{,}\), because this notation only squares the 3, note the minus sign.
    🔗
    Instead, we should wrap the -3 in parentheses:
    \begin{equation*} (-3)^2 = (-3)\times(-3) = 9 \end{equation*}
    🔗
    🔗

    Example 5.2.5.

    Given that \(x=-2\text{,}\) evaluate the expression:
    \begin{equation*} 5-x \end{equation*}
    🔗
    It would not be correct to write \(5 - -2\text{,}\) since we should not have two minus/negative signs directly next to each other.
    🔗
    Instead, we should wrap the -2 in parentheses:
    \begin{equation*} 5-(-2) = 5+2 = 7 \end{equation*}
    🔗
    🔗

    Example 5.2.6.

    Given that \(x=-4\text{,}\) evaluate the expression:
    \begin{equation*} 3x \end{equation*}
    🔗
    Solution: It would not be correct to write 3-4, since this notation means “subtract 3 and 4”, but we want “multiply 3 by negative 4.”
    🔗
    Instead, we should wrap the -4 in parentheses:
    \begin{equation*} 3(-4) = -12 \end{equation*}
    🔗
    🔗

    Be Careful!

    Whenever you’re doing an evaluation problem with a negative value, it is recommended to wrap the negative number in parentheses.
    🔗
    🔗
    If a variable appears in a formula multiple times, you need to replace EVERY instance of that variable with its value.
    🔗

    Example 5.2.7.

    Given that \(x=2\text{,}\) evaluate the expression
    \begin{equation*} x^2 + 3x + 1 \end{equation*}
    🔗
    Solution: Replace every \(x\) in the expression with 2:
    \begin{equation*} 2^2 + 3(2) + 1 \end{equation*}
    \begin{equation*} 4+6+1 = 11 \end{equation*}
    🔗
    🔗
    Formulas can contain two or more different variables.
    🔗

    Example 5.2.8.

    Given that \(L=5\) and \(W = 7\text{,}\) evaluate the formula:
    \begin{equation*} 2L + 2+W \end{equation*}
    🔗
    Solution: Replace every \(L\) with 5 and \(W\) with 7:
    \begin{align*} 2(5)+2(7)\amp = 10+14 \\ \amp = 24 \end{align*}
    🔗
    🔗

    Evaluate the following expressions at the given values:
    🔗

    1.

    Evaluate \(3x+5\) when \(x=4\text{.}\)
    🔗
    🔗

    2.

    Evaluate \(2a^2-3a+7\) when \(a=2\text{.}\)
    🔗
    🔗

    3.

    Evaluate \(5y-2z\) when \(y=6\) and \(z=3\text{.}\)
    🔗
    🔗

    4.

    Evaluate \(x^3-4x\) when \(x=2\text{.}\)
    🔗
    🔗

    5.

    Evaluate \(4m^2+3n\) when \(m=1\) and \(n=5\text{.}\)
    🔗
    🔗

    6.

    Evaluate \(2(p+3)-5\) when \(p=7\text{.}\)
    🔗
    🔗

    7.

    Evaluate \(6x-x^2+4\) when \(x=3\text{.}\)
    🔗
    🔗

    8.

    Evaluate \(\frac{1}{4}a+b-5\) when \(a=2\) and \(b=\frac{1}{3}\text{.}\)
    🔗
    🔗

    9.

    Evaluate \(2(x-1)^2+3\) when \(x=5\text{.}\)
    🔗
    🔗

    10.

    Evaluate \(7y^2-2y+1\) when \(y=-1\text{.}\)
    🔗
    🔗

    11.

    If a car travels at a speed R, for a length of time T, the distance they travel is given by the formula
    \begin{equation*} R \times T \end{equation*}
    If the car’s speed is 40 miles per hour, and they drive for 1.4 hours, find the total distance traveled.
    🔗
    🔗

    12.

    If the temperature in the room is C degrees Celsius, then the temperature in degrees Fahrenheit is
    \begin{equation*} \frac{9}{5}C+32 \end{equation*}
    If the temperature in the room is 27 degrees Celsius, find the temperature in Fahrenheit.
