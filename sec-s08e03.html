    Section 8.3 Episode 3: Solving Inequalities, Part 2

    Episode 3 Overview.

    • Solve compound inequalities
      🔗
      🔗
    • Write solutions to linear inequalities in interval notation.
      🔗
      🔗
    🔗
    🔗
    We solve regular equalities and inequalities by performing the same action on both sides:
    🔗
    For example, in
    \begin{equation*} 2x=6 \end{equation*}
    we divide both sides by 2:
    \begin{equation*} \frac{2x}{2} = \frac{6}{2} \end{equation*}
    \begin{equation*} x=3 \end{equation*}
    🔗
    For example, in
    \begin{equation*} x + 3 \ge 7 \end{equation*}
    We subtract 3 from both sides:
    \begin{equation*} x+3-3 \ge 7 - 3 \end{equation*}
    \begin{equation*} x \ge 4 \end{equation*}
    🔗
    When we have a compound inequality, like
    \begin{equation*} 3 \le x + 5 \le 7 \end{equation*}
    We can solve the inequality by performing the same action in all three parts of the inequality. To get rid of the added 5 next to \(x\text{,}\) we can subtract 5 from all three parts.
    \begin{equation*} 3-5 \le x + 5 - 5 \le 7 - 5 \end{equation*}
    \begin{equation*} 2 \le x \le 7 \end{equation*}
    🔗

    Example 8.3.1.

    Solve the inequality and write your answer in interval notation.
    \begin{equation*} -7 \le 2x+1 \le 9 \end{equation*}
    🔗
    Solution: We start by subtracting 1 from all three parts, so that only variable terms are left in the center:
    \begin{equation*} -7-1 \le 2x+1-1 \le 9-1 \end{equation*}
    \begin{equation*} -8 \le 2x \le 8 \end{equation*}
    Then we divide all three parts by 2, to get rid of the multiplied 2 on the \(x\text{:}\)
    \begin{equation*} \frac{-8}{2} \le \frac{2x}{2} \le \frac{8}{2} \end{equation*}
    \begin{equation*} -4 \le x \le 4 \end{equation*}
    This says that \(x\) can be between -4 and 4, including -4, but not including 4. In interval notation, that would be
    \begin{equation*} [-4, 4] \end{equation*}
    🔗
    🔗
