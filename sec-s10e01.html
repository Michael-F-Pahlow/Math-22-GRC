    Section 10.1 Episode 1: Solve Systems of Equations by Graphing

    Episode 1 Learning Goals.

    • Interpret a system of linear equations, and interpret a solution to a system
      🔗
      🔗
    • Solve a system of linear equations by graphing both equations and looking for the point of intersection
      🔗
      🔗
    🔗
    🔗

    Episode 1 Key Terminology.

    • System of equations
      🔗
      🔗
    • Solution to a system of equations
      🔗
      🔗
    🔗
    🔗

    Episode 1 Key Symbols.

    \begin{equation*} \left\{ \right. \quad\quad \text{as in} \,\, \left\{ \begin{array}{l} x+ y = 1\\ 2x-y = 2 \end{array}\right. \end{equation*}
    🔗
    🔗

    Definition 10.1.1.

    A system of equations consists of two or more equations that need to be true simultaneously.
    🔗
    🔗
    Equations can be collected into a system by enclosing them with a left curly bracket, for example:
    \begin{equation*} \left\{ \begin{array}{l} x+ y = 1\\ 2x-y = 2 \end{array}\right. \end{equation*}
    Remember that a single equation can be used to express a desired result or a known fact. So a system of equations can be used to represent multiple desired results, or multiple known facts.
    🔗

    Example 10.1.2.

    A rectangle has an unknown length L and a width W. You want to make a rectangle with a perimeter of 20 inches and an area of 25 square inches. Express this situation using a system of equations.
    🔗
    Solution: First, you want the perimeter to be 20 inches. Using the perimeter formula for a rectangle, this becomes the equation:
    \begin{equation*} 2L+2W=20 \end{equation*}
    Second, you want the area to be 25 square inches. Using the area formula for a rectangle, this becomes the equation:
    \begin{equation*} LW = 25 \end{equation*}
    Because I want both of these things to be true at the same time, I write both equations in a system:
    \begin{equation*} \left\{ \begin{array}{l} 2L + 2W = 20\\ LW = 25 \end{array}\right. \end{equation*}
    A solution to a single equation is something that makes the equation true. It tells you how to achieve the result that the equation represents.
    🔗
    A solution to a system of equations is something that makes ALL the equations true at the same time. It tells you how to simultaneously achieve all the results that the equations represent.
    🔗
    🔗

    Example 10.1.3.

    Verify that \(L=5, W =5\) represents a solution to the system
    \begin{equation*} \left\{ \begin{array}{l} 2L + 2W = 20\\ LW = 25 \end{array}\right. \end{equation*}
    🔗
    I need to be able to plug \(L=5\) and \(W=5\) into BOTH equations and make BOTH equations true. Plugging the values into the first equation:
    \begin{align*} 2(5) + 2(5) \amp = 20 ? \\ 10+10 \amp = 20 ? \\ 20 \amp = 20 ? \end{align*}
    This is true, so \(L=5\) and \(W=5\) is a solution to the first equation.
    🔗
    Let’s plug the values into the equation:
    \begin{align*} (5)(5) \amp = 25?\\ 25 \amp = 25? \end{align*}
    This is true, so \(L=5\) and \(W=5\) is also a solution to the second equation.
    🔗
    Because \(L=5\text{,}\) \(W=5\) was a solution to both equations, it is a solution to the system of equations.
    🔗
    In other words, to make a rectangle that has a perimeter of 20 inches and an area of 25 inches, you should make a rectangle that has a length of 5 inches and a width of 5 inches.
    🔗
    🔗
    Remember that the points on the graph of an equation correspond to the solutions to that equation. So, if a point is on the graph of two equations, it must be a solution to both equations.
    🔗
    How to Solve a System of Equations by Graphing:
    1. Graph the equations on the system. Make sure to draw both graphs on the same xy-plane.
      🔗
      🔗
    2. Look for points where the graphs intersect (points on the graph of both equations).
      🔗
      🔗
    3. The point of intersection is the solution to the system.
      🔗
      🔗
    🔗

    Example 10.1.4.

    Solve the system of equations:
    \begin{equation*} \left\{ \begin{array}{l} y = -2x+1\\ y = x-2 \end{array}\right. \end{equation*}
    🔗
    Solution: We start by graphing both equations.
    🔗
    The first equation, \(y=-2x+1\text{,}\) has a slope of \(-2\) and a y-intercept of \((0,1)\text{.}\) We use the techniques of Season 09 to quickly graph this equation.
    🔗
    The second equation, \(y=x-2\text{,}\) has a slope of \(-2\) and a y-intercept of \((0,-2)\text{.}\) We use the techniques of Season 09 to quickly graph this equation too.
    🔗
    Notice that the point \((x,y)=(1,-1)\) lies on both lines; it is the point where the two lines intersect. So, \(x= 1, y=-1\) is the solution to the system.
    🔗
    🔗

    Example 10.1.5.

    Solve the system of equations:
    \begin{equation*} \left\{ \begin{array}{l} x+y = 2\\ x-2y =4 \end{array}\right. \end{equation*}
    🔗
    Solution: We start by graphing both equations.
    🔗
    The first equation is not currently written in slope-intercept form, so we start by solving for \(y\text{.}\)
    \begin{align*} x+y \amp = 2 \\ x+y-x \amp = 2-x \\ y \amp = 2-x \\ y \amp = -x+2 \end{align*}
    Now we can see the first equation has a slope of \(m=-1\) and a y-intercept of \((0,2)\text{,}\) which we can use to graph the equation quickly.
    🔗
    The second equation is also not written in slope-intercept form, so we start by solving for \(y\text{:}\)
    \begin{align*} x-2y \amp =4\\ x-2y -x\amp =4-x\\ 2y \amp =4-x\\ \frac{-2y}{-2}\amp =\frac{4-x}{2}\\ y \amp \frac{4}{-2} - \frac{x}{-2}\\ y \amp =-2+x\\ y \amp =x-2 \end{align*}
    Now we can see that the second equation has a slope of \(m=1\) and a y-intercept of \((0,-1)\text{,}\) which we can use to graph the equation quickly:
    🔗
    Notice that the point \((x,y)=(2,0)\) lies on both lines; it is the point where the two lines intersect. So, \(x=2,y=0\) is the solution to the system.
    🔗
