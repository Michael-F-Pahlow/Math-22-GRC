    Section 9.2 Episode 2: Plotting Points

    Episode 2 Learning Goals.

    • Graph an equation by plotting points
      🔗
      🔗
    🔗
    🔗

    Episode 2 Key Terminology.

    • Graph
      🔗
      🔗
    🔗
    🔗
    In Episode 01, we used the xy-plane to visually display values of \(x\) that are paired with specific values of \(y\text{.}\)
    🔗
    Given an equation relating \(x\) and \(y\text{,}\) the graph of the equation is the visual display of ALL its paired \(x\) and \(y\) values.
    🔗
    To Plot the Graph of an Equation
    1. Create a table with two columns.
      1. In the left column, fill up the table with several x-values. (It’s common to use integers like -2,-1,0,1,2, but for some equations, other x-values might be easier to work with.)
        🔗
        🔗
      2. Plug each of those x-values into your equation to find the associated y-values, and put those y-values into the right column of the table.
        🔗
        🔗
      🔗
      🔗
    2. Turn each of the pairs in the table into an ordered pair (\(x\text{,}\)\(y\)) and draw all those points on the same xy-plane.
      🔗
      🔗
    3. Draw a line or curve through the dots to create the graph.
      🔗
      🔗
    🔗

    Example 9.2.1.

    Graph the equation
    \begin{equation*} y=2x-1 \end{equation*}
    🔗
    Solution: We begin by constructing a table of values. We fill up the left column with the standard x-values, -2,-1,0,1,2. Then we plug each of those x-values into the formula \(y=2x-1\) to find the corresponding y-value.
    🔗
    \(x\) \(y\)
    -2 \(2(-2)-1=-5\)
    -1 \(2(-1)-1=-3\)
    0 \(2(0)-1=-1\)
    1 \(2(1)-1=1\)
    2 \(2(2)-1=3\)
    Now we plot the points (-2,-5), (-1,-3), (0, -1), (1, 1), (2,3) all on the same xy-plane.
    🔗
    Notice that all the dots are lie on a straight line. We draw a straight line through all the points. The line is the graph of \(y=2x+1\text{.}\)
    🔗
    🔗

    Example 9.2.2.

    Graph the equation
    \begin{equation*} y=x^2 \end{equation*}
    🔗
    Solution: We begin by constructing a table of values. We fill up the left column with the standard x-values, -2,-1,0,1,2. Then we plug each of those x-values into the formula \(y=x^2\) to find the corresponding y-value.
    🔗
    \(x\) \(y\)
    -2 \((-2)^2=4\)
    -1 \((-1)^2=1\)
    0 \((0)^2=0\)
    1 \((1)^2=1\)
    2 \((2)^2=4\)
    Now we plot the points (-2,4), (-1,1), (0, 0), (1, 1), (2,4) all on the same xy-plane.
    🔗
    Now, we draw a curve that goes through all the points. The curve is the graph of \(y=x^{2}\text{.}\)
    🔗
    🔗

    Example 9.2.3.

    Challenge: Graph the equation
    \begin{equation*} y=\sqrt{x} \end{equation*}
    🔗
    Solution: We begin by constructing a table of values. In this cast, it’s not a good idea to use the standard x-values, -2,-1,0,1,2.
    🔗
    That’s because you cannot calculate the square root of a negative number like -2 or -1. Instead, let’s make sure we’re using non-negative x-values, like 0, 1, 2, 3, 4.
    🔗
    Then we plug each of those x-values into the formula \(y=\sqrt{x}\) to find the corresponding y-value.
    🔗
    \(x\) \(y\)
    0 \(\sqrt{0}=0\)
    1 \(\sqrt{1}=1\)
    2 \(\sqrt{2}\approx 1.4\)
    3 \(\sqrt{3}\approx 1.7\)
    4 \(\sqrt{4}=2\)
    Now we plot the points (0,0), (1,1), (2, 1.4), (3, 1.7), (4,2) all on the same xy-plane.
    🔗
    Now we draw a curve through the dots. This time, we are not going to draw anything on the left half of the \(xy\)-plane, because the left half of the xy-plane has negative \(x\)-values, and we can’t plug negative \(x\)-values into \(\sqrt{x}\text{.}\)
    🔗
    This curve is the graph of \(y=\sqrt{x}\text{.}\)
    🔗
    🔗
