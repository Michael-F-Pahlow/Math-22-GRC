    Section 6.1 Episode 1: What Equations Represent

    Episode 1 Learning Goals.

    • Interpret equations as a statement of a desired result or known fact.
      🔗
      🔗
    • Interpret equations as a statement of equality / balance.
      🔗
      🔗
    • Determine whether a given value is a “solution” to an equation.
      🔗
      🔗
    🔗
    🔗

    Episode 1 Key Terminology.

    • Equation
      🔗
      🔗
    • Solution
      🔗
      🔗
    🔗
    🔗

    Definition 6.1.1.

    An equation is a line of mathematics containing an = sign. Equations communicate that the quantity on the left side of the = sign is equal to the quantity on the right side of the = sign.
    🔗
    🔗
    For example, we have written lines like:
    \begin{equation*} \frac{2}{4} = \frac{1}{2} \end{equation*}
    This communicates that, although the two fractions look different, the fraction 2/4 represents the same physical amount as the fraction 1/2.
    🔗
    We have also written lines like:
    \begin{equation*} \frac{3}{4} = 0.75 \end{equation*}
    \begin{equation*} 0.20 = 20\% \end{equation*}
    Again, equations like these communicate that the quantity on the left is the same as the quantity on the right, although the two quantities look different.
    🔗
    Equations containing variables can be used to express known facts.
    🔗

    Example 6.1.2.

    Represent Amanda’s age by the letter A. If you know that Amanda’s age is 35, write down the equation that expresses this fact.
    🔗
    Solution: If Amanda’s age is 35, that corresponds to the equation
    \begin{equation*} A = 35 \end{equation*}
    🔗
    🔗

    Notice Something Neat!

    The keyword “is” usually corresponds to an = sign, the same way the keyword “of” usually corresponds multiplication.
    🔗
    🔗

    Example 6.1.3.

    Represent the cost of a dozen eggs by a variable, C. If you know that the total cost of buying 3 dozen eggs is $7, write down an equation that expresses this fact.
    🔗
    Solution: The expression that represents the cost of buying 3 dozen eggs is
    \begin{equation*} 3C \end{equation*}
    If I know that this cost is $7, that becomes the equation
    \begin{equation*} 3C = 7 \end{equation*}
    🔗
    🔗

    Be Careful!

    An expression does NOT contain an = sign. It represents a quantity that can’t be fully calculated yet because it involves a variable.
    🔗
    An equation contains an = sign. It represents a known fact or a desired result.
    🔗
    🔗

    Example 6.1.4.

    Represent the length of a rectangle by a variable L and the width of the rectangle by a variable W. If you know that the rectangle’s area is 30 square inches, write down an equation that expresses that fact.
    🔗
    Solution: We remember that a rectangle’s area is equal to the product of its length and its width:
    \begin{equation*} LW \end{equation*}
    If we know that this area is 30, that becomes the equation
    \begin{equation*} LW = 30 \end{equation*}
    🔗
    🔗
    Equations containing variables can also be used to express desired results or targets.
    🔗

    Example 6.1.5.

    Represent the number of cakes by a variable, \(N\text{.}\) Making a single cake requires 2 eggs. You have 6 eggs that are about to go bad, and you want to make enough cakes to use up all of them. Write down an equation that expresses this desire.
    🔗
    Solution: If you make \(N\) cakes, and each cake requires 2 eggs, then the total number of eggs used is given by the expression
    \begin{equation*} 2N \end{equation*}
    If we want to use 6 eggs, that becomes the equation
    \begin{equation*} 2N=6 \end{equation*}
    🔗
    🔗

    Example 6.1.6.

    Represent the cost of a house by a variable, B. You plan to make 25% of the house cost as a down payment. If you only want to put $80,000 down, write down an equation that expresses this desire.
    🔗
    Solution: The expression representing the down payment is 25% of B:
    \begin{equation*} 0.25B \end{equation*}
    If we want to put $80,000 down, that becomes the equation
    \begin{equation*} 0.25B = 80,000 \end{equation*}
    🔗
    🔗

    Definition 6.1.7.

    A solution to an equation is a value that can replace the variable in the equation and make the equation true. Solutions tell you how to achieve the desired result that the equation represents.
    🔗
    🔗

    Example 6.1.8.

    Show that \(N=1\) is NOT a solution to the equation \(2N=6\text{.}\)
    🔗
    To show that \(N=1\) is NOT solution, we just need to plug \(N=1\) into the equation and see if it makes the equation true or false.
    \begin{align*} 2(1)\amp = 6 ? \\ 2\amp = 6 ? \end{align*}
    Because 2 is definitely NOT the same as 6, this is proof that \(N=1\) is NOT a solution. In other words, if we want to use up 6 eggs, making just 1 cake is not going to work.
    🔗
    🔗

    Example 6.1.9.

    Show that \(N=3\) is a solution to the equation \(2N=6\text{.}\)
    🔗
    To show that \(N=3\) is a solution, we just need to plug \(N=3\) into the equation and see if it makes the equation true or false.
    \begin{align*} 2(3)\amp = 6 ? \\ 6\amp = 6 ? \end{align*}
    Because 6 is the same as 6, this is proof that \(N=3\) is a solution. In other words, if we want to use up 6 eggs, we can accomplish that by making 3 cakes.
    🔗
    🔗

    Example 6.1.10.

    Show that \(B=650,000\) is NOT a solution to the equation \(0.25B=80,000\text{.}\)
    🔗
    To show that \(B=650,000\) is NOT a solution, we just need to plug \(B=650,000\) into the equation and see if it makes the equation true or false.
    \begin{align*} 0.25(650,000)\amp = 80,000 ? \\ 162,500\amp = 80,000 ? \end{align*}
    Because 162,500 is not the same as 80,000, this is proof that \(B=650,000\) is not a solution. In other words, if we want to put only $80,000 down, then we cannot buy a house costing $650,000.
    🔗
    🔗

    Example 6.1.11.

    Show that \(B=320,000\) is NOT a solution to the equation \(0.25B=80,000\text{.}\)
    🔗
    To show that \(B=320,000\) is NOT a solution, we just need to plug \(B=320,000\) into the equation and see if it makes the equation true or false.
    \begin{align*} 0.25(320,000)\amp = 80,000 ? \\ 80,000\amp = 80,000 ? \end{align*}
    Because 80,000 is not the same as 80,000, this is proof that \(B=320,000\) is not a solution. In other words, if we want to put only $80,000 down, then we cannot buy a house costing $320,000.
    🔗
    🔗
