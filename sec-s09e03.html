    Section 9.3 Episode 3: Interpreting Graphs

    Episode 3 Learning Goals.

    • Given a graph representing a real-world relationship, answer questions and make conclusions using the graph.
      🔗
      🔗
    🔗
    🔗
    Remember that a graph is a visual representation of the relationship between two quantities. If you have a graph, you can answer lots of different questions about the two quantities.
    🔗

    Example 9.3.1.

    The following graph shows the relationship between the year (on the horizontal axis) and the population of a certain town (on the vertical axis).
    🔗
    Part 1-A: What was the town’s population during the year 1891?
    🔗
    Solution 1-A: Start with the given information: Look for \(y=1\) on the vertical axis. Then, navigate to the point on the graph that has a vertical coordinate of 1. Then, look to the horizontal axis to see the x-value.
    🔗
    Part 1-B: When did the population reach 100 thousand people?
    🔗
    Solution 1-B: Start with the given information: Look for 100 (thousand) on the vertical axis. Find the point on the graph with that vertical coordinate. Then look down to the horizontal axis for the year.
    🔗
    The year on the vertical axis is between 1921 and 1951, slightly closer to 1951. So, a reasonable answer is that the population reached 100 thousand in approximately the year 1940.
    🔗
    🔗

    Example 9.3.5.

    Below is a graph of some equation relating two quantities \(x\) and \(y\text{.}\)
    🔗
    Part 1-A: Find the value of \(x\) that is paired with \(y=1\text{.}\)
    🔗
    Solution 1-A: Start with the given information: Look for \(y=1\) on the vertical axis. Then, navigate to the point on the graph that has a vertical coordinate of 1. Then, look to the horizontal axis to see the x-value.
    🔗
    The value on the horizontal axis is between 1 and 2. So a reasonable answer would be that \(x=1.5\) is the x-value that is paired with \(y=1\text{.}\)
    🔗
    Part 1-B: Find the value of \(y\) that is paired with \(x=\text{.}\)
    🔗
    Solution 1-B: Start with the given information: Find \(x=0\) on the horizontal axis. Then, navigate to the point on the graph that has a horizontal coordinate of 0. Then, look to the vertical axis to find the y-value.
    🔗
    The point has a vertical coordinate of 2. So \(x=0\) is paired with a y-value of 2.
    🔗
    Part 1-C: Find the value of \(x\) that is paired with \(y=0\text{.}\)
    🔗
    Solution 1-C: Start with the given information: Find \(y=0\) on the vertical axis. Then, navigate to the point on the graph that has a vertical coordinate of 0. Then, look to the horizontal axis to find the x-value.
    🔗
    The point has a horizontal coordinate of 3. So \(x=3\) is paired with \(y=0\text{.}\)
    🔗
    🔗

    Notice Something Neat!

    If the x-coordinate is \(x=0\text{,}\) the point lies on the y-axis.
    🔗
    If the y-coordinate is \(y=0\text{,}\) the point lies on the x-axis.
    🔗
    🔗

    Example 9.3.10.

    Below is a graph of some equation relating two quantities \(x\) and \(y\text{.}\)
    🔗
    Part 1-A: Find the value of \(y\) paired with \(x=1\text{.}\)
    🔗
    Solution 1-A: Start with the given information: look for \(x=1\) on the horizontal axis. Navigate to the point on the graph with that horizontal coordinate. Then look over to the y-axis for the vertical coordinate.
    🔗
    The value \(x=1\) is paired with the value \(y=1\text{.}\)
    🔗
    Find the value(s) of \(x\) paired with \(y=4\text{.}\)
    🔗
    Solution 1-B: Start with the given information and look for \(y=4\) on the vertical axis. There are two points on the graph with that vertical coordinate. We look down to the x-axis for their horizontal coordinates.
    🔗
    The x-values \(x=-2\) and \(x=2\) are paired with \(y=4\text{.}\)
    🔗
    🔗
